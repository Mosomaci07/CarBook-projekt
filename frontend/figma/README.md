# Figma – Frontend látványtervek

Ebben a mappában tároljuk a CarBook frontendjéhez tartozó Figma-látványterveket és a hozzájuk kapcsolódó dokumentációkat.

## Ide kerülhetnek

- Képernyőtervek és exportált látványtervek (`.png`, `.jpg`, `.svg`)
- Figma-exportok vagy projektfájlok (`.fig`, ha rendelkezésre állnak)
- A frontend képernyőinek leírásai és specifikációi (`.pdf`, `.md`, `.docx`)
- Komponensek, színek, betűtípusok és UI-elemek dokumentációja

## Javasolt rendezés

A fájlokat érdemes képernyő vagy funkció szerint elnevezni, például:

- `login-screen.png`
- `dashboard-screen.png`
- `vehicle-details-screen.png`
- `frontend-ui-specification.pdf`

A tényleges frontend-forráskód továbbra is a `frontend/src/` mappába kerüljön.
