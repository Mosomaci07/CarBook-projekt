# CarBook – autónyilvántartó webalkalmazás | Vehicle Management Web Application

## Magyar

A CarBook célja, hogy a felhasználók egy helyen kezelhessék autóik adatait, szervizeléseit, tankolásait, kiadásait, hibakódjait, emlékeztetőit és dokumentumait.

### Projekt felépítése

- `frontend/` – HTML, CSS és JavaScript alapú felhasználói felület
- `backend/` – PHP szerveroldali logika és REST API
- `database/` – MySQL adatbázis-séma és ER-diagramok
- `fullstack/` – frontend-backend integráció és közös tesztek
- `docs/` – projekttervek és dokumentáció

### Technológiák

HTML · CSS · JavaScript · PHP · MySQL

### Adatbázis

Az adatbázis neve: `carbook_db`. A séma a `database/schema.sql` fájlban található.

---

## English

CarBook is designed to help users manage all their vehicle-related information in one place, including vehicle details, maintenance records, refueling history, expenses, error codes, reminders, and documents.

### Project Structure

- `frontend/` – User interface built with HTML, CSS, and JavaScript
- `backend/` – PHP server-side logic and REST API
- `database/` – MySQL database schema and ER diagrams
- `fullstack/` – Frontend-backend integration and shared tests
- `docs/` – Project plans and documentation

### Technologies

HTML · CSS · JavaScript · PHP · MySQL

### Database

The database is named `carbook_db`. Its schema is located in the `database/schema.sql` file.
