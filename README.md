# CarBook – autónyilvántartó webalkalmazás

A CarBook célja, hogy a felhasználók egy helyen kezelhessék autóik adatait, szervizeléseit, tankolásait, kiadásait, hibakódjait, emlékeztetőit és dokumentumait.

## Projekt felépítése

- `frontend/` – HTML, CSS és JavaScript alapú felhasználói felület
- `backend/` – PHP szerveroldali logika és REST API
- `database/` – MySQL adatbázis-séma és ER-diagramok
- `fullstack/` – frontend-backend integráció és közös tesztek
- `docs/` – projekttervek és dokumentáció

## Technológiák

HTML · CSS · JavaScript · PHP · MySQL

## Adatbázis

Az adatbázis neve: `carbook_db`. A séma a `database/schema.sql` fájlban található.
